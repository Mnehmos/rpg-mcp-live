# Changelog

All notable changes to Lantern are documented here.

The changelog is generated automatically by `tools/ci/generate-changelog.mjs`
from conventional-commit squash-merge messages. Every PR title must follow
`type(scope): description (#NN)` — this is enforced by the CI metadata gate
and is the sole input to changelog generation.

The format is based on [Conventional Commits](https://www.conventionalcommits.org/).
